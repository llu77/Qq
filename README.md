# Qq - Claude API Guidelines

مرجع شامل ومحسن لـ Claude API متوافق 100% مع الوثائق الرسمية (ديسمبر 2025).

## المحتويات

يتضمن هذا المستودع دليلاً شاملاً يغطي:

- التوجيهات السلوكية الأساسية ومنهجية البحث والتحليل
- نماذج Claude 4.5 المدعومة (Opus, Sonnet, Haiku)
- التفكير الممتد (Extended Thinking) والتحكم في الذاكرة المؤقتة
- أدوات البحث على الويب والاستشهادات
- أسباب التوقف ومعالجة الاستجابات
- Batch API و Streaming المتقدم
- Computer Use API
- Claude Code Analytics API
- دليل الترحيل إلى Claude 4.5
- منهجية OSINT المتكاملة
