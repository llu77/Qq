# Qq - Claude API Guidelines

مرجع شامل ومحسن لـ Claude API متوافق 100% مع الوثائق الرسمية (ديسمبر 2025).

## المحتويات

يتضمن هذا المستودع دليلاً شاملاً يغطي:

- التوجيهات السلوكية الأساسية ومنهجية البحث والتحليل
- نماذج Claude 4.5 المدعومة (Opus, Sonnet, Haiku)
- التفكير الممتد (Extended Thinking) والتحكم في الذاكرة المؤقتة
- أدوات البحث على الويب والاستشهادات
- أسباب التوقف ومعالجة الاستجابات
- Batch API و Streaming المتقدم
- Computer Use API
- Claude Code Analytics API
- دليل الترحيل إلى Claude 4.5
- منهجية OSINT المتكاملة

## الملفات

- `CLAUDE_API_GUIDELINES.md` - الدليل الشامل لـ Claude API
- `OSINT_ENGINEER_SYSTEM_PROMPT.xml` - System Prompt لمهندس OSINT محسن لـ Claude 4.5
- `OSINT_USER_STYLE.xml` - User Style Configuration مع أمثلة عملية للردود

## الاستخدام

راجع ملف `CLAUDE_API_GUIDELINES.md` للحصول على توثيق كامل مع أمثلة الكود.

للاستخدام كـ OSINT Engineer:
1. استخدم `OSINT_ENGINEER_SYSTEM_PROMPT.xml` كـ system prompt
2. استخدم `OSINT_USER_STYLE.xml` كـ user style في Claude Projects
